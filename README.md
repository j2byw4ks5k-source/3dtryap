# 空間認識トレーナー

3次元CADで必要な「断面」と「矢視（投影図）」を頭の中ですばやく正確に組み立てる力を、ゲーム感覚で鍛えるスマホ向けWebアプリです。

- 形状 **122種**（基本立体／段付き・切欠き／穴加工／機械部品／回転体／相貫体／パズル）
- **断面当て**：赤い切断面で切ったとき、矢印の向きに見た断面を4択で選ぶ
- **矢視当て**：矢印の方向から見た図（第三角法・隠れ線あり）を4択で選ぶ
- 回答後は3Dで切断アニメーション、または視点がその方向へ回り込んで答え合わせ
- 誤答は「鏡像」「切断位置違い」「別方向の図」「隠れ線の誤り」「似た別形状」など、ありがちな間違いから自動生成
- 苦手な形状を優先して出題、成績は端末内に保存
- 座標系は **Z上**、正面図は −Y 側から見た図

## 開発

```bash
npm install
npm run dev          # 開発サーバ
npm test             # 形状・断面・隠れ線・問題生成のテスト
npm run check-shapes # 全形状の生成チェック
npm run build        # dist/ に出力
```

## 構成

| ディレクトリ | 役割 |
|---|---|
| `src/shapes/` | 形状定義（ブーリアン演算の DSL）。カテゴリ別ファイル |
| `src/geometry/` | manifold-3d 連携、断面計算、隠れ線処理付き投影 |
| `src/quiz/` | 問題・誤答生成、図の同一判定 |
| `src/render/` | Three.js の 3D 表示、SVG の 2D 図 |
| `src/ui/` | 画面とゲーム進行 |
| `src/storage/` | 学習記録（localStorage） |

詳細は [docs/PLAN.md](docs/PLAN.md)。

## 形状の追加

`src/shapes/*.ts` の配列に追加するだけです。

```ts
{ id: 'C99', name: '座ぐり付き横穴', cat: 'hole', diff: 2,
  build: (S) => S.D(S.box(-25, -20, 0, 25, 20, 30), S.cyl('x', 6, -26, 26, 0, 15)) },
```
